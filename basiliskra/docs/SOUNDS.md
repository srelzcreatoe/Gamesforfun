# Basiliskra - sound inventory

> Generated by `tools/sound/synth.py`. Do not edit by hand - change the script and re-run it.

- **46 events, 69 files**, 125.0 s of audio, 1201 kB.
- Every sound is original procedural synthesis (numpy only: modal bodies, additive formant voices,
  filtered noise, FM, granular events, synthetic-impulse-response reverbs). No samples, no downloads.
- Format: mono, 44100 Hz, Ogg Vorbis (`ffmpeg -c:a libvorbis -q:a 4 -ac 1`). Mono is required for
  Bedrock to spatialise a sound.
- Deterministic: every file has a fixed seed, `crc32("<event>#<variant>")`.
- Regenerate everything: `python3 basiliskra/tools/sound/synth.py` (from the repository root).
  Add `--spectro DIR` for spectrogram PNGs, `--only TEXT` to render a subset.

## Review status - read this first

**Nobody has listened to any of these files.** They were designed from first principles and checked
by machine only: each `.ogg` is decoded again with ffmpeg and must be mono / 44.1 kHz / Vorbis, within
0.1 s of its nominal duration, peak <= -1.0 dBFS, free of DC, and start and end near zero. Spectrograms
of the key sounds were inspected by eye. Timbre, believability and in-game balance still need human ears;
the "Review" column records that.

## The knock motif

`basiliskra.knock.gill` N and `basiliskra.knock.vent` N are built on the *same* body (`knock_body()`,
seeded by the variant number only): fundamental 112/105/118 Hz, a short downward settle on the attack,
a hollow partial at 2.07x, a cavity puff and a woody click. Gill = that body through a 900 Hz 4-pole
low-pass with a slight droop and a bubble flutter; vent = the same body dry, plus a steam burst and a ping.
Play three of either, ~0.5-0.6 s apart, for the motif.

## Notes for whoever wires these up

- `sound_definitions.json` uses `format_version` 1.20.20 with explicit `min_distance` / `max_distance`,
  the same entry shape as the vanilla 1.26.60 file (object-form `sounds` entries with `name`, `volume`,
  `load_on_low_memory`). Categories used: hostile, neutral, ambient, block.
- `basiliskra.rift.hum` is a seamless loop: its content is periodic over exactly 3.000 s (the wrap from
  the last sample to the first is continuous). A 3 ms safety fade at each end keeps a re-trigger that is
  a tick early or late from clicking. Re-trigger it every 60 ticks.
- `basiliskra.iii.charge` stops dead at its peak (4 ms fade). Start `basiliskra.iii.beam` on the same tick.
- `basiliskra.iii.charge_tick` sits exactly on 440 Hz with harmonic partials; re-pitch it freely.
- `basiliskra.scrape_far` and `basiliskra.fin_pulse` are deliberately quieter than the rest.
- All "through water" sounds have the muffling baked in; do not add another low-pass.
