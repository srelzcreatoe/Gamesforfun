# Credits & licenses

## Cubic World original content

All of the following was created originally for Cubic World in this
repository (largely generated by the deterministic scripts in `tools/`):

- **Textures** — every block/item/creature tile in `assets/textures/atlas.png`
  is rendered procedurally by `tools/gen_textures.py` from the data-driven
  recipes in `assets/data/*_tiles.json` / `tiles.json`. No external art.
- **Launcher icon & splash** — drawn procedurally by `tools/gen_icons.py`.
- **Audio** — every sound effect, ambience loop and music track in
  `assets/audio/` is synthesized from scratch by `tools/gen_sounds.py`
  (seeded, deterministic). The four music loops are original compositions
  with invented pentatonic melodies.
- **Game data** — block set, item stats, recipes, biomes, creatures, names
  and lore (Worldheart, Resonance, Cubeforgers, Waystones, all creature and
  biome names) are original to this project.
- **Code** — all Kotlin/GLSL/Python in `core/`, `android/`, `desktop/`,
  `tools/` was written for this project.
